# Data provenance

Both files are synthetic and were written by hand for this repo on 2026-10-30.

- `index.json` is the searchable catalogue. It holds only id, name, city and category.
- `details.json` is served by the local record service. Certifications, lead time and contact email exist only here, so a question about them cannot be answered from search alone.

Company names are invented. Every email uses the reserved `.example` domain (RFC 2606) and cannot reach anyone. Dataset version: `suppliers-v1`.
